# RET Chair — Target Assignment

Assign Research and Extension targets to faculty, guided by the rank rules you configured.

![Target Assignment](/static/img/ret-chair/03-target-assignment.png)

## Assigning targets

1. Go to **Target Assignment**.
2. Choose a faculty member (or work per indicator).
3. For each indicator, set the **quantity** and the **deadline (duration)**.
4. Save.

## Research vs Extension

| Type | How it reaches faculty |
| --- | --- |
| **Research** | Self-selected from the pool at the quantity-per-rank you configured |
| **Extension** | Distributed automatically per the rank rules (mandatory) |

## Eligibility

- Each faculty member's **eligibility** is governed by your rank-based rules; people outside
  a rule's rank band are not eligible for that target.
- **Auto Divide** fills the assigned quantity as *Dean quota ÷ total regular faculty*, which
  is the standard starting point for Extension.

## Deadline required

You cannot save a target without a valid **duration**. Set the value and unit (days, weeks,
months, semesters) for every assigned row.
